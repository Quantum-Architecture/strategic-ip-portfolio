## Disclosure rule

Published:
- problem addressed;
- public functional purpose;
- deployment context;
- non-sensitive evidence categories;
- integration boundaries.

Not published:
- enabling algorithms;
- claim-construction detail;
- internal thresholds or weights;
- cryptographic secrets;
- unpublished source code;
- defence-sensitive material;
- confidential test harnesses.

## Evidence policy

Public evidence is separated from enabling IP.

Examples:
- governed AI evidence → `qec-governed-agent-demo`;
- audit-chain verification → `ledger-verify`;
- QEC architecture → `qec-overview`.

## Status language

Preferred:
- “patent application”;
- “patent filing”;
- “filed with INPI”;
- “public functional summary”.

Avoid “granted patent” unless formally granted.
